# デスクトップの背景（テーマ）の仕様・下書き

状態：1.12.0 で作った。下の「決めたこと」は、作るときに決めた答え。

## ねらい

デスクトップのアプリの背景に、Clawd のいる場面を描く。行進にはこだわらない。背景の役目は 2 つ。

1. **作業中のマスコット**：そばにいて、いっしょに働いている感じがする。じゃまにならない
2. **今のようすが分かる窓**：ちらっと見れば「調べもの中」「書いている」「止まって待っている」「おわった」が分かる

なでる・♡・ショップ・セリフは、今までどおり入力欄の上の帯でやる。背景はさわれない（押した操作は上の会話に届く）。

## 試作（#46）で分かった制約

| 制約 | わけ | どうするか |
| --- | --- | --- |
| 動きは SVG の中の CSS で、ずっと動かす | 背景を描き直すと絵がまるごと入れかわり、チカチカするうえ、CSS のアニメーションも最初からやり直しになる | 描き直すのは場面が変わったときだけ。動きは CSS の `@keyframes` で、なめらかにくり返すもの（ゆれる・はねる・流れる・降る・またたく） |
| 背景を描くフックは、場面の名前しか見ない | フックが state を読むと、その state が変わるたびに描き直される | `$.theme.set({ backdrop: { scene } })` の `scene` に、絵を決めるものを全部入れる（例：`desk-night-rain-winter-3`）。フックは `e.props.scene` だけから絵を作る |
| 場面を変えすぎない | 変えるたびに描き直しになる。ツールは数秒ごとに変わる | ツールを大まかな「しごと」にまとめ、場面は少なくとも 10 秒くらいは変えない |
| 真ん中・下の端・左右には大事なものを置かない | 真ん中は会話、下の端は入力欄、左にサイドバー、右に右のパネルが重なる。その幅はエンジンから読めない | おへやは窓の右下（会話の列の外の、床の上）に置く。`/parade theme left` で左下にも置ける（下の「決めたこと」） |
| SVG は 131,072 文字まで | `Svg` の `source` の上限 | ドット絵は色ごとに 1 本の path にまとめる（今の `toSvg` と同じ）。いちばんにぎやかな場面でも 8 万字くらいまでに |
| 動きを減らす設定では止める | 公式の例と同じ。アプリも GPU が無いときは止める | `@media (prefers-reduced-motion: reduce) { * { animation: none } }`。止まっても場面が分かる絵にしておく |
| テーマはセッションに 1 つ | ほかのプラグインのテーマと取り合う | 入れる・外すのは `/parade theme` で頼まれたときだけ（今の試作と同じ） |

試作では、0.6 秒ごとにコマをめくる形にしたが、ひまなときは変わるところがほとんど無く、止まって見えた。描き直しで 1 コマ目に戻っていた疑いもある（確かめていない）。今度はコマをめくらず、場面ごとの動きを CSS で描く。

## 場面

Claude のようすを、いくつかの「しごと」に分け、しごとごとに場面を 1 つ用意する。場所は「Clawd のおうちの部屋」を基本にして、しごとに合わせて小物と動きを変える（場所ごと切りかえるより絵が少なくてすみ、切りかわっても落ち着いて見える）。

| しごと | どんなとき（今の帯の状態・ツール） | 場面の案 | 動き |
| --- | --- | --- | --- |
| くつろぐ | ひま（idle） | ソファでくつろぐ・窓の外をながめる | ゆっくり呼吸・しっぽ（ねこ）・湯気 |
| ねむる | 3 分なにもない（sleeping） | 毛布にくるまって寝る。部屋は暗め | Zzz が浮かぶ・寝息 |
| しらべる | Read・Grep・Glob・WebFetch・WebSearch | 本棚の前で本をめくる・虫めがね | ページがめくれる・目が左右に動く |
| かく | Edit・Write・NotebookEdit | 机でキーボードを打つ | 手がカタカタ・画面の行が増える |
| うごかす | Bash・テストやビルド | 机のとなりの機械（歯車・ランプ） | 歯車が回る・ランプが点く |
| たたかう | エラーで止まった（error）・テストが落ちた | バグ（小さな虫）と向き合う | バグがちょろちょろ・Clawd が身がまえる |
| まつ | 許可待ち・質問・プラン（permission・question・plan） | ドアの前で札を持って待つ | 札をふる・「?」がはねる |
| なかま | サブエージェントがいる | 部屋に仲間が来て、それぞれ机やすみで働く | 仲間が小さくはねる。人数ぶん増える |
| おわった | done | ばんざい・紙ふぶき | 紙ふぶきが一度落ちて、くつろぐにもどる |
| とめられた・できない | aborted・refusal | しょんぼり座る | 小さくゆれる |

- 「なかま」は、ほかのしごとに重ねる（Clawd が書いていて、仲間が調べもの、など）
- 「おわった」と「たたかう」は、少したったら「くつろぐ」にもどす
- 時間帯・天気・季節は、窓の外の景色と部屋のあかりで出す（朝は明るい窓、夜はランプ、雨の日は窓に雨つぶ、冬は窓に雪）。今のパレードの空（星・太陽・雲・季節の飾り）を、窓の中に持っていける

## ショップとのつながり

背景を強くする品をショップで買えるようにする。

- **部屋のもの（新しい品）**：ランプ・観葉植物・ポスター・ラグ・本棚の本・ねこの寝床など。買うと部屋に増える
- **今の品を部屋に**：
  - ぼうし → Clawd がかぶる（今と同じ）
  - 流れ星・オーロラ → 窓の外の夜空に
  - おくりもの（クッキー・ココアなど） → 少しのあいだ机の上に
  - 夢のプレゼント → 部屋か窓の外に（図書館 → 大きな本棚、望遠鏡 → 窓ぎわ、月への旅 → 窓の外の月とロケット、など）
  - 贈った星 → 窓の外の星が増える
- 部屋のものは、背景を出していないときも帯の絵に出すかどうかを決める（決めること 5）

## 帯との分担

| | 背景 | 帯 |
| --- | --- | --- |
| Clawd と仲間 | 場面の中に大きく | 小さく（または出さない） |
| セリフ・タイマー・♡ | 出さない（すりガラスの下で読めない） | 出す |
| なでる | できない | できる |
| 動き | CSS でずっと | 今までどおり |

## 作り方の要点

- 場面の名前に、絵を決めるものを入れる：しごと・仲間の数（3 匹くらいまで）・時間帯・天気・季節・部屋のもの（買ったものを短い記号で）。長くなるので、64 文字に収まるよう記号にする（`scene` は 1〜64 文字の英数字と `_` `-`）
- 名前が変わったときだけ `$.theme.set` を呼ぶ。しごとは少なくとも 10 秒保つ
- フックは名前を読んで SVG を作る。同じ名前なら必ず同じ SVG
- 絵は今のドット絵の部品（Clawd・ねこ・仲間・ぼうし・夢の飾り）を使い回し、部屋の部品を足す。動く部分は `<g class="…">` に分けて、CSS で動かす
- 作っているあいだだけ、フックが描いた回数をデバッグログに書き、描き直しすぎていないかを見る
- テスト：同じ名前なら同じ SVG／場面が変わらないあいだは `theme.set` を呼ばない／しごとの切りかえは 10 秒あける／いちばんにぎやかな場面でも文字数の上限に収まる／動きを減らす設定の CSS が入っている

## 決めたこと

1. **場所**：おうちの部屋 1 つ。しごとごとに、Clawd のいる場所（ソファ・机・本棚の前・床）と小物と動きを変える。場所ごと変えるより、切りかわっても落ち着いて見え、絵も少なくてすむ
2. **置き場所**：おへやの絵は、窓の右下に床に立つように置く（横は窓の 59〜99%、床は高さの 84%）。`/parade theme left` で左下にできる。かべと床は窓いっぱいに塗る
3. **大きさ**：おへやの絵は窓の幅の 40%・高さの 62% の枠に収める（72×54 ドット）。Clawd は 18 ドット幅
4. **しごとの分け方**：上の 10 個（くつろぐ・ねむる・かんがえる・しらべる・かく・うごかす・バグとたたかう・おへんじ待ち・おわった・しょんぼり）。「なかま」はほかのしごとに重ねる
5. **部屋のものと帯**：背景だけに出す（帯の絵は変えない）
6. **値段**：600〜30,000♡（ランプ・観葉植物・ラグ・ポスター・ガーランド・金魚ばち）。きせかえの品として売り、出す・しまうができる
7. **明るさ**：おへやはいつも暗めにして、画面は暗い色にそろえてもらう（`overrideColorScheme: 'dark'`）。時間帯は窓の外の空と、かべの色で出す
8. **画面の色**：変えない（`colors` は使わない）
9. **帯**：背景を出しているあいだ、デスクトップの帯はセリフと「なでる」ボタンだけ
