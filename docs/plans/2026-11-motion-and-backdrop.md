## 守ること（今の作りから来る制約）

- 絵は **場面の名前（`sceneName`、64 文字まで）だけ** から決まる。場面が変わると SVG がまるごと描き直しになる。同じ場面の中の動きは CSS の `@keyframes` のくり返しだけ
- 場面は 10 秒くらいは変えない（`HOLD_MS`）
- SVG は 131,072 文字まで。今いちばんにぎやかな場面でも 6 万字未満（`tests/room.test.tsx`）
- `@keyframes` に `vw` を書く・入れ子の svg に `shape-rendering="crispEdges"` を付ける、のどちらでも、アプリの背景でアニメーションが全部止まる（`docs/backdrop-investigation.md`）。**CSS の書き方を足したら、アプリで動くかを必ず見る**（ブラウザでは再現しない）
- 動きを減らす設定（`prefers-reduced-motion`）では、止まった絵で何をしているか分かること
- Clawd とねこ（`neko`）の両方で成り立つこと

## 1. モーションのバリエーション

### 1-0. 土台：しごとの「バリエーション」を持てるようにする

今は「しごと（Activity）→ 絵」が 1 対 1。これを「しごと＋バリエーション番号 → 絵」にする。

- 場面の名前に 1 文字足す：`r1-re0-…` → `r2-re30-…`（`re` のあとの `3` がバリエーション。36 種まで）。名前は今 20 字台なので 64 字に余裕がある。頭を `r2` にして古い名前とまざらないようにする
- バリエーションは `Held`（`holdActivity` の持ちもの）に入れて、しごとと同じタイミングでだけ変える。仲間が増えた・時間帯が変わっただけで、急に別のポーズに飛ばないように
- 選び方（**決めること A**）
  - 案 1（おすすめ）：しごとが変わったときに選ぶ。前と同じものは避ける。くつろぐだけは、3 分で寝るまでのあいだに 60 秒ごとに 1 回変える（3 分で 2〜3 種見られる）
  - 案 2：作業中も、同じしごとが 90 秒以上続いたら変える
- 作業中は、ツールの意味で選べるものは固定する（WebSearch・WebFetch → web 検索、Grep・Glob → フォルダ探し など）。意味で分けられないもの（Read・Edit・Bash）は、そのしごとの中から選ぶ（**決めること B**：意味で固定するか、全部ランダムか）
- 大きな絵の切りかえは場面の名前で、同じ絵の中の小さな変化（12〜20 秒に 1 回電球が光る、スマホから ♡ が飛ぶ）は CSS の長いくり返しで、と分ける。1 つの SVG に別のポーズを何個も入れて CSS で切りかえるのはやめる（文字数がふくらみ、作業中は 10〜20 秒でしごとが変わるので後半が見られない）

## 2. モーション・バグの改善

### 2-1. おへんじ待ちで、ぼうしが札のうしろに隠れる

- 「灯台」は、頭の上の「??」の札のことだと読んだ（ちがっていたら教えてください）
- 原因：`roomSvg` で、ぼうしを Clawd と同じ層に描いたあと、札（`sign()`）をその上に重ねている。札が頭のすぐ上（`hy - 12`）にあるので、王冠などは下の端だけ札の下からのぞく（`current.png` の wait）
- 直し方の案：ぼうしがあるときは札をぼうしの高さぶん上げる（かんがえるの「…」と同じやり方）。あわせて、ぼうしを札より後に描く

### 2-2. 目を閉じたときに、元の四角い目のふちが見える

- 原因（コードから）：まばたきは、目をあけた絵の上に「違うマスだけ」の層（`.blink`）を重ねて出している。背景では `crispEdges` を付けられない（付けるとアニメが止まる）ので、ドットのふちがぼやけ、下の黒い目のふちが細くすけて見える。体がゆれる（`.br` の `scaleY`、`.bob`）と小数の位置になり、さらに出やすい
- 出る場面：目をあけていて、まばたきするしごと（くつろぐ・かんがえる・かく・うごかす・しらべる・おへんじ待ち）
- 直し方の案：重ねるのをやめる。「あいた目」の層と「閉じた目」の層を分けて、片方を消すときにもう片方を出す（重なるマスが無くなる）。新しい CSS になるので、アプリで動くかを確かめる

### 2-3. しらべるの本

- 今：白い長方形の本が体のまんなかに重なっていて、エプロンのように見える。左右の行が交互に点滅するだけで、めくっているように見えない。右上の「?」は質問中に見える
- 直し方の案
  - 本を V 字の見開きにする（綴じ目を 1 ドット低く）。体の中心から 2〜3 ドットずらして、体のふちからはみ出させる。目を 1 ドット下げて、本を見下ろす
  - めくり：3 秒のうち 2 秒は止まって読み、残り 1 秒で 3 コマ（右ページが立つ → 綴じ目の上に縦線 → 左へ倒れる）。止まっているあいだは開いた本なので、動きを減らす設定でも分かる
  - 「?」を虫めがね（7×7。銀のわく・水色のレンズ・左上に白い光 1 ドット・右下に茶色の柄）に変え、本のななめ上で小さく円をえがいて動かす

### 2-4. （見つけたもの）動きを減らす設定で、コードの行・「…」・Zzz が消える

- `.ln`（かくのコードの行・かんがえるの「…」）と `.zz`（ねむるの Zzz）は `opacity:0` から始まる。動きを減らす設定では `animation:none` になるので、ずっと見えない。仕様の「止まった絵でも分かる」に合わない
- 直し方の案：動きを減らす設定のときだけ、これらを見える形（`opacity:1`）にする

### 3-2. 雨のアニメーション（issue #50 とまとめる）

- 今：96px 四方のもように縦の雨つぶ 4 本（2×10px）。x が 24px おき・y もほぼ 24px おきで、格子に見える。0.6 秒で 96px 落ちて速い
- 直し方の案
  - **斜めの細い線**：もようの中は縦の細い線のまま、もようを敷いた rect を `skewX(-12deg)` の g で傾ける。傾いた枠の中で縦に落とすだけで、線の向きと落ちる向きがそろい、つなぎ目も出ない（rect は傾いても端が欠けないよう広めに）
  - **3 層**：遠い雨（1×12px・うすい・遅い）、中くらい（1.5×20px）、近い雨（2×28px・少し濃い・本数少なく・速い）。近い雨だけおうちと庭の手前に描くと立体感が出る
  - **格子をなくす**：層ごとに、もようの大きさと速さを整数の比にしない（例：137×140・193×180・269×240、1.37 秒・0.83 秒・0.53 秒）。1 枚の中の線は位置・長さ・濃さをばらつかせ、6〜10 本にする。層ごとに傾きを 1〜2° ずらす
  - **しぶき**：地面と屋根に、2×1 の小さなはねを数か所、交互に点滅
  - **窓の中の雨**（部屋の窓）も、外と同じ向きの斜めにする
- 雪（`.flurry`）も同じ格子の問題があるので、同じ issue で 2〜3 層にする
